Título do Projeto: Incentivador Bíblico

Objetivos:
Este projeto foi desenvolvido com o intuito de acolher os usuários e oferecer vesículos bíblicos, para que melhorem o seu dia.
Ele foi criado durante uma atividade prática de Git e GIthub, com práticas em estilização e aperfieçoamento de CSS simples em aplicações web.


Funcionalidades:
- Fundo dinâmico de acordo com ação do usuário
- Mensagens bíblicos aleatórias
- Pop-up centralizado exibindo a mensagem
- Layout simplista e acolhedor
  

Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
  

Como executar
- Baixe os arquivos do projeto
- Abra o arquivo "index.html"
- Clique no botão "Receba sua Benção!"
